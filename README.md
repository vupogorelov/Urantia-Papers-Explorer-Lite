# Urantia Papers Explorer Lite

Автономная мобильная читалка Книги Урантии для Android. Приложение хранит книгу и данные чтения на устройстве; для проверки и загрузки обновлений нужно подключение к интернету.

## Возможности

- чтение русских и английского текстов, навигация и локальный поиск;
- сохранение позиции, закладки и заметки;
- озвучивание системным TTS в фоне;
- проверка обновлений через колокольчик и просмотр описания релиза;
- сборка Android APK с постоянным именем `upexplorer.apk`.

## Сборка

```powershell
npm run build
```

APK будет в `dist/upexplorer.apk`. Для собственной release-сборки задайте `ANDROID_BUILD_VARIANT=release`, `ANDROID_KEYSTORE_PATH`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS` и `ANDROID_KEY_PASSWORD`.

## Скачать APK

[Скачать актуальный APK](https://github.com/vupogorelov/Urantia-Papers-Explorer-Lite/releases/latest/download/upexplorer.apk) — постоянная ссылка на файл последнего GitHub Release. В самом приложении колокольчик показывает обновления и описание изменений. При нажатии «Обновить» Android скачивает APK и открывает системный установщик; установку нужно подтвердить.

## Выпуск обновления

GitHub Actions собирает и прикрепляет APK при публикации тега вида `v0.1.1`. Подпись должна оставаться одной и той же, чтобы Android разрешал обновление поверх установленной версии. Для этого в Settings → Secrets and variables → Actions добавьте secrets:

- `ANDROID_KEYSTORE_BASE64` — keystore в Base64;
- `ANDROID_KEYSTORE_PASSWORD`;
- `ANDROID_KEY_ALIAS`;
- `ANDROID_KEY_PASSWORD`.

Версия приложения следует SemVer: `MAJOR.MINOR.PATCH`. Исправления ошибок увеличивают PATCH (`0.1.0` → `0.1.1`), обратно совместимые функции — MINOR (`0.1.1` → `0.2.0`), несовместимые изменения — MAJOR (`0.9.0` → `1.0.0`). Тег релиза становится `versionName` Android-приложения без начальной буквы `v`; внутренний `versionCode` автоматически увеличивается в GitHub Actions.

Чтобы выпустить новую версию, создайте и отправьте новый тег. Например, для следующего исправления после `v0.1.1`:

```powershell
git tag v0.1.2
git push origin v0.1.2
```

Workflow проверяет, что тег имеет формат SemVer и версия выше последнего релиза. Повторный запуск уже начатой сборки можно сделать кнопкой **Re-run jobs** в GitHub Actions.

## Разработка

После `npm run build:web` локальный preview можно запустить так:

```powershell
python -m http.server 4181 --directory web/public
```

Затем откройте `http://127.0.0.1:4181`.
