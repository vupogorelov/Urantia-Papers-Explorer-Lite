# Формат локальной книги

## Исходники

`book/sources/` содержит проверенные RU/EN Markdown-источники. Они находятся внутри Lite-проекта, поэтому генерация контента не зависит от старого SaaS-проекта.

Файлы исходников переносятся без изменения их издательских уведомлений. Перед публичным распространением APK нужно отдельно проверить условия использования обоих переводов.

## Сборка

`npm run build:content` валидирует исходники и создаёт `book/generated/`:

- `manifest.json` — версия формата, число сущностей, имена источников и SHA-256 исходников;
- `toc.json` — части, тексты и названия разделов;
- `papers/paper-{id}.json` — параграфы и разделы одного текста.

`scripts/build-web.js` копирует сгенерированную книгу в Android assets для APK и в `web/public/book/` для браузерной проверки. Эти производные файлы не нужно редактировать вручную.

## Модель

- Текст имеет числовой `id`; Предисловие использует `0`.
- Стабильная ссылка на параграф — `paperId:sectionNum.paragraphNum`, например `5:1.3`.
- `htmlRu` и `htmlEn` содержат подготовленную разметку текста; `plainRu` и `plainEn` предназначены для поиска и будущих аннотаций.
- Позиция чтения ссылается на `ref`, а не на пиксельную координату экрана, поэтому остаётся пригодной при изменении размера шрифта и ориентации.

Формат имеет собственную `formatVersion`; любое несовместимое изменение схемы требует увеличения версии и проверки миграции.
